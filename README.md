# ARKK Tech Solutions

**ARKK Tech Solutions** is a modern, responsive business website designed to showcase the company's digital services, projects, career opportunities, and contact channels. The website combines a clean professional interface with interactive sections and direct communication features to make it easy for potential clients and candidates to connect with ARKK.

## 🌐 Live Website

**https://arkktechsolutions.com**

## ✨ Features

* 🎬 **Video Hero Section** — Dynamic video-based hero section for a modern first impression.
* 💼 **Services Section** — Presents the services offered by ARKK Tech Solutions.
* 👨‍💻 **Careers Section** — Allows users to apply for opportunities directly through WhatsApp with a pre-filled message.
* 📩 **Contact Form** — Multi-step contact form for collecting name, phone number, email, and project requirements.
* ✉️ **Email Integration** — Contact submissions are delivered directly to the company's email using EmailJS.
* ✅ **Form Validation** — Prevents users from submitting incomplete contact information.
* 💬 **WhatsApp Integration** — Direct communication with the company through WhatsApp.
* 📱 **Responsive Design** — Optimized for desktop and mobile devices.
* 🧭 **Smooth Navigation** — Structured navigation across the website's major sections.
* 🎨 **Custom Branding** — ARKK branding, logo, typography, and visual styling throughout the website.
* 🌍 **Custom Domain** — Deployed with the custom domain `arkktechsolutions.com`.

## 📩 Contact Workflow

The website uses a two-step contact experience:

1. Users enter their **name, phone number, and email**.
2. Users describe their project requirements.
3. The form validates the required information.
4. The submission is sent to the company's email through **EmailJS**.
5. A styled success message is displayed after successful submission.
6. The form resets for the next enquiry.

## 💼 Career Application Workflow

When a visitor selects **Apply** in the Careers section:

1. WhatsApp is opened.
2. The company's WhatsApp number is targeted.
3. A predefined application message is generated.
4. The candidate can review and send the message directly.
